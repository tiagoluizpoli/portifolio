# Data Model: Zenith CMS Restoration (Iteration 5)

## [Round 4] Impact Metrics & Sources (AD-001)

### MetricSource (Registry)
Centralized visual and telemetry definition.

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `id` | string | Yes | Autogenerated (`ID.unique()`) |
| `name` | string | Yes | e.g., "LinkedIn", "GitHub", "Manual" |
| `type` | string | Yes | `manual` \| `automated` |
| `iconCode` | string | Yes | Default icon (e.g., `lucide:database`) |
| `functionId` | string | No | Link to Appwrite Function for telemetry |
| `status` | string | Yes | `active` \| `archived` |

---

### ImpactMetric (Refined)
Thin record linked by semantic anchor.

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `id` | string | Yes | Autogenerated (`ID.unique()`) |
| `internalCode` | string | Yes | **Primary Anchor**. Unique per locale. |
| `locale` | string | Yes | en, pt, etc. |
| `sourceId` | string | Yes | Link to MetricSource.id |
| `label` | string | Yes | Localized label |
| `value` | string | No | Computed or user-entered value |
| `iconCode` | string | No | **Override Icon**. Use if set; elsewhere use Source.iconCode. |
| `isPlaceholder` | boolean | Yes | Defaults to `false` (True for Ghost Rows) |

---

## [Relationships & Cascading Deletion]

1. **ImpactMetric -> MetricSource**: Many-to-One.
   - **Cascade**: Deleting a `MetricSource` MUST delete all related `ImpactMetric` records.
2. **ImpactMetric -> ImpactMetric**: Parity Link (via `internalCode`).
   - **Cascade**: Deleting an `ImpactMetric` record MUST trigger a search-and-destroy for all records sharing the same `internalCode` across all locales (`deleteByInternalCode`).

---

## [Constraints & Indices]
- **ImpactMetric**: `UniqueIndex(locale, internalCode)` — Mandatory for parity logic.
