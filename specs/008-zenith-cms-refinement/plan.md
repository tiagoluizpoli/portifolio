## Technical Context

- **Data Strategy**: Shift to `ID.unique()` for all records. Semantic identity resides in `internalCode`.
- **Normalization Layer**: UI hook joins `ImpactMetric` with `MetricSource` metadata.
- **Cascading Logic**:
    - **Source-to-Metric**: Deleting a source purges all related metrics.
    - **Parity-to-All**: Deleting a metric purges its counterparts across all locales via `internalCode`.
- **UI Interaction**: "Automated" sources lock the value field; "Manual" allows entry.
- **CSS Precision**: Remove native numeric spinners using `appearance: textfield` and `::-webkit-inner-spin-button`.
