# Design System: Portfolio Manager (Refined Administrative)
**Project ID:** 6063674963019114840

## 1. Visual Theme & Atmosphere
The Portfolio Manager aligns with the **"System Settings"** functional architecture. The atmosphere is professional, integrated, and high-density — mirroring administrative interfaces like macOS Settings. Boundaries are defined by subtle tonal shifts and negative space.

- **Density:** Cockpit Dense (8/10)
- **Variance:** Predictable Symmetric (3/10)
- **Motion:** Fluid CSS (4/10)

## 2. Color Palette & Roles
- **Oceanic Deep** (#0b1326) — Primary Canvas Background
- **Surface Elevation** (#131b2e) — Grouped containers and input zones (Card base)
- **Elevated Border** (#49445433) — Ghost borders for subtle separation
- **Executive White** (#dbe2fd) — Primary content and high-contrast labels
- **Muted Zinc** (#cbc3d7) — Secondary metadata and narrative snippets
- **Success Violet** (#d0bcff) — Singular accent for active toggles and primary CTAs

## 3. Typography Rules
- **Display:** Geist Variable — Track-tight, weight-driven hierarchy
- **Body:** Inter — baseline readability, 65ch max-width
- **Mono:** Geist Mono — For numbers and technical metadata

## 4. Component Stylings
* **Rounding**: Conservative `rounded-xl` (12px) for containers and `rounded-lg` (8px) for inputs.
* **Separators**: Use subtle dividers for list items.
* **Layout**: Grouped rows with left-aligned labels.

## 5. Layout Principles
- **No forced dark menus**: Sidebars and footers are transparent/integrated with the glassmorphic shell.
- **Grouped Categories**: Settings organized into logical containers.
