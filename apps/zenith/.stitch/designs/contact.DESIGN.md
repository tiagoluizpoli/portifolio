# Design System: Portfolio Contact Section (The Reachability Layer)
**Project ID:** 6063674963019114840

## 1. Visual Theme & Atmosphere
The Contact Section focuses on **Reachability Orchestration**. It provides a clean, direct, and authoritative environment for managing how the world connects with the curator. The vibe is "Accessible Executive": professional, efficient, and meticulously organized.

## 2. Color Palette & Roles
| Descriptive Name | Hex Code | Functional Role |
| :--- | :--- | :--- |
| **Oceanic Obsidian (Base)** | `#0b1326` | Deepest background layer. |
| **Muted Onyx (Surface)** | `#171f33` | Background for the contact information grid. |
| **Social Card Surface** | `#2d3449` | Background for individual Social Link Cards. |
| **Connect Violet** | `#8B5CF6` | Primary icons and link submission accents. |

## 3. Typography Rules
- **Contact Labels**: Inter ExtraBold (text-[10px]) with 0.2em tracking for a precise instrument feel.
- **Reachability Data**: Manrope SemiBold (text-base) for email and location data to ensure they feel substantial.

## 4. Component Stylings
- **Contact Grid**: A 1:1 or 1:2 grid of high-fidelity input cards with Lucide icons as visual anchors.
- **Social Link Cards**: Vertical cards that combine a service brand icon with a URL orchestration field.
- **Sync Action**: A prominent header-level button for final deployment of connectivity status.

## 5. Layout Principles (Desktop)
- **Direct Access**: Core contact fields (Email, Phone) are staged prominently in the primary view.
- **Social Grid**: A dedicated area for managing the "Visual Orbit" (GitHub, LinkedIn, etc.) using the curation card pattern.
- **Executive Header**: Consistent with all chapters, using the Chapter 07 title and brand violet accents.
