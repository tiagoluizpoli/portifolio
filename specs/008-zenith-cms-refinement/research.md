# Research: Zenith CMS Refinement (Rounds 4-5)

## 1. Semantic Metric Parity (Round 4) — AD-001 Refinement
### Current Implementation
- Metrics use custom IDs (`metric_xxx`).
- Icons are stored redundantly per metric record.
- Telemetry sources are not formally typed or tied to server logic.

### Decisions (Iteration 4 / AD-001)
- **ID Strategy**: Transition to Appwrite Autogenerated IDs (`ID.unique()`) for all entities. Semantic identity is governed by `internalCode`.
- **Iconography Hierarchy**:
    - Default Icon: Provided by the `MetricSource`.
    - Manual Override: `ImpactMetric.iconCode` (optional) allows per-metric branding §XXII.
    - Result: `Display_Icon = ImpactMetric.iconCode ?? MetricSource.iconCode`.
- **Telemetry Engine**: 
    - Automated sources are linked to Appwrite Server Functions via `functionId`.
    - These functions populate the `value` field across all localized records bearing the same `internalCode`.
- **Ghost Row Logic**: 
    - Creating a metric generates `isPlaceholder: true` rows in alternate locales.
    - Placeholders inherit the `internalCode`, `sourceId`, and `iconCode` (if overridden).
- **Cascading Deletion Logic**:
    - **Parity Deletion**: Deleting an `ImpactMetric` in the CMS triggers `deleteByInternalCode`, purging the entry and its ghost rows across all locales.
    - **Source Deletion**: Deleting a `MetricSource` must cascade to all `ImpactMetric` records linked via `sourceId` to prevent orphaned metrics.
- **Data Integrity**: Enforce a unique index on **`(locale, internalCode)`** to prevent collision in the parity engine.

## 2. Home Admin Split-Layout (Round 5)
### Current Implementation
- 3-column grid; Slider for year selection.

### Decisions
- **Grid Realignment**: Shift to `lg:grid-cols-2` (1:1 split).
- **Metadata Column (Left)**: Concentrated identity inputs (Name, Headline, Bio, Year).
- **Asset Column (Right)**: High-fidelity file uploaders with borderless previews for Picture and CV.
- **Precision Input**: Switch "Journey Started" to `<Input type="number">`. 
- **Spinner-Free Implementation**: Apply global or scoped CSS to hide browser-native numeric arrows (spinners).
    ```css
    /* Chrome, Safari, Edge, Opera */
    input::-webkit-outer-spin-button,
    input::-webkit-inner-spin-button {
      -webkit-appearance: none;
      margin: 0;
    }
    /* Firefox */
    input[type=number] {
      -moz-appearance: textfield;
    }
    ```
