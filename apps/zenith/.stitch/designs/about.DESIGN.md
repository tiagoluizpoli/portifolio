# Design System: Portfolio About Section (The Narrative Core)
**Project ID:** 6063674963019114840

## 1. Visual Theme & Atmosphere
The About Section focuses on **Narrative Orchestration**. It provides a high-density environment for professional storytelling, balancing long-form prose with structured impact metrics. It strictly adheres to the **Nocturnal Executive** vibe: tonal, deep, and precisely staged.

## 2. Color Palette & Roles
| Descriptive Name | Hex Code | Functional Role |
| :--- | :--- | :--- |
| **Oceanic Obsidian (Base)** | `#0b1326` | Main background. |
| **Muted Onyx (Surface)** | `#171f33` | Background for the narrative editor card. |
| **High-Contrast Onyx** | `#2d3449` | Background for metric input cards and hovered states. |
| **Brand Violet** | `#8B5CF6` | Accents, labels, and status highlights. |

## 3. Typography Rules
- **Narrative Bio**: Inter (Semantic Sans) with relaxed line height (`leading-loose`) for maximum readability of professional backstories.
- **Impact Metrics**: Manrope Bold for numbers/results and Inter SemiBold for labels to create a hierarchy of achievement.

## 4. Component Stylings
- **Tonal Editor**: A large `#171f33` surface with no borders. Interactive focus is indicated by a subtle Violet Lavender glow or tonal shift.
- **Metric Cards**: Small, modular `#2d3449` cards with tight spacing. They house "Value" and "Label" pairs.
- **The "No-Line" Rule**: Borders are avoided; card boundaries are defined by tonal shifts against the `#0b1326` base.

## 5. Layout Principles (Desktop)
- **Primary/Secondary Split**: 70% width for the Narrative Bio, 30% for the Impact Metrics sidebar.
- **Vertical Rhythm**: Large gaps (`gap-12`) between sections to distinguish the story from the data.
- **Audit Strip**: Violet progress bar at the bottom for maturity tracking.
